# AI04 — 降级手动箱「跳过此单元」= 整条流水线静默终止

严重度:中 / 方向:AI 管线 / 确认度:confirmed

## 问题

aiPipeline 中某单元抛错 → 降级手动箱 → 用户点「跳过此单元」(_manualUnit 以 false resolve)→ runBatch 直接 `return ok(false)`(html:2925-2928),**后续单元全部不再执行**,且无任何完成/失败提示。用户以为"跳过这个继续下一个",实际整条流水线(如 work2 评估体系、work3 主张定位/人格 Slogan)就此中断,下游字段全空;重跑时还会从被跳过的单元开始,与按钮文案"跳过此单元"的语义不符。

代码注释写的是"完成/跳过后从下一单元继续(新 Runner 批次)"——实现与注释矛盾。

## 期望

跳过 = 继续下一单元(i++ 后 runBatch);仅在明确放弃时才终止且给出提示。

## 复现

1. 任一多单元流水线(AI 评估体系/主张定位/Slogan),让某单元触发失败(如网络断);
2. 手动箱点「跳过此单元」;
3. 流水线静默结束,后续单元字段全空,无任何提示。

## 证据

- docs/global-brand-building.html:2925-2928 — `if(!ok || i>=units.length) return ok`

## 修复方向

跳过时继续下一单元;全部完成/真正放弃时给明确 toast。
