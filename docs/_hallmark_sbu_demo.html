STEP 1.1

业务三问（独立 SBU 自检）

3 QUESTIONS · 任一为"是"即独立

三问中任一答"是"，即构成独立 SBU，须在客户/渠道/品牌/损益四维至少一项独立核算。

01

客户是否不同？

B 端 / C 端、整机厂 / 经销商、自有用户 / 客户配套……

STATUS
不独立
02

渠道是否不同？

ODM 配套 / Amazon 零售 / 经销批销 / 自建 DTC……

STATUS
独立 · 渠道
03

品牌是否独立露出？

贴客户 logo / 自有 logo、母品牌子品牌关系……

STATUS
不独立
→ Verdict 独立 SBU · 需在四维（客户/渠道/品牌/损益）至少一项独立核算 Independent
▎ 边界声明

说明与母公司其他业务在客户、渠道、品牌、损益四维上的隔离点，以及复用/共享的资源（供应链、研发、资质等）。
