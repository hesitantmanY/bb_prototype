# 工作坊-3 确定价值主张与业务定位

## 3.1 目标市场细分与场景需求强度

**目标**：把 W2 选定的目标市场（一个国家/区域）拆成 3–5 个细分场景，标注每个场景的需求强度（高/中/低）与购买驱动力。

**工作内容**：

1. 在 W2 选定的目标市场内做人群细分
   - 切分维度建议：人口学（年龄/家庭结构）+ 行为学（使用情境/购买驱动）+ 心理（价值取向）
   - 输出 3–5 个细分场景，每个场景须满足：① 客群规模可估算；② 痛点可被现有产品功能命中；③ 竞品未垄断心智
2. 对每个场景做需求强度评分（1–10），三维：
   - 痛点真实度：用户是否真的为此困扰
   - 支付意愿：愿为解决痛点多付多少钱
   - 决策频率：多久发生一次相关购买/替换决策
3. 选定 3 个主战场场景（默认三场景并行打法，特殊情况下可缩为 2 个或扩为 4 个）

**产出物**：
- 场景细分表（场景名 / 客群描述 / 估算规模 / 需求强度均分 / 选为 / 不选 + 理由）
- 三场景需求强度对比图（柱状图或雷达图）

## 3.2 备选卖点池构建

**目标**：从 W1 价值体系的 15 个测评点 + 三场景痛点中，提炼出 5–9 个候选卖点，进入下一步双维评分。

**工作内容**：

1. **三场景共性卖点**（2–3 项）
   - 满足：跨场景通用、技术/认证底座、产品架构优势
   - 例：三场景模式切换、跨场景认证背书、核心硬件精度
2. **场景差异化卖点**（每场景 1–2 项，共 3–6 项）
   - 满足：精准命中该场景痛点、竞品未覆盖、与品牌定位相关
   - 例：母婴场景=异常温度报警；睡眠场景=睡眠算法；民宿场景=多房间 dashboard
3. **次级支撑卖点**（1–2 项）
   - 不进入主推，但用于背书与可信度建设
   - 例：温控精度、伴侣双账号联动

**方法**：
- 用 W1 价值体系表中得分 ≥6 分的测评点作为种子
- 抓取目标市场 Amazon/Reddit/垂类论坛 Top 5 竞品的 1–3 星差评，提取高频痛点词
- 用 LDA 或简单词频统计验证痛点是否构成卖点候选

**产出物**：
- 备选卖点清单（编号 / 卖点名称 / 适用场景 / 一句话描述 / 数据或证据来源）

**工具**：
- 八爪鱼（爬取 Amazon 评论、Reddit 话题、垂类 KOL 内容）
- 简单 LDA 主题模型或词频工具（Excel/Python）

## 3.3 "客户合意性"问卷调研

**目标**：让目标客群为每个备选卖点打分，量化"客户想要什么"。

**工作内容**：

1. 问卷设计：每个卖点对应一个题组，3 个维度
   - **重要性**（1–10）：这个卖点对你有多重要
   - **独特性**（1–10）：这个卖点跟竞品比是不是不一样
   - **可信性**（1–10）：你相信品牌能兑现这个承诺吗
2. 投放策略
   - 每个场景至少回收 50 份有效问卷（合计 ≥150 份）
   - 渠道：Amazon 评论者招募、Reddit 相关 subreddit、Facebook 群组、SurveyCircle
3. 数据清洗
   - 剔除完成时间 <60 秒、直线作答、注意力题答错的样本
   - 每个场景保留 ≥30 份有效样本进入打分

**评分规则**：客户合意性 = 重要性 × 独特性 × 可信性的几何均值（或加权和，各 1/3 权重）

**产出物**：
- 客户合意性得分表（卖点 / 三维分 / 均分 / 排名）
- 调研样本画像表（场景 / 样本量 / 国家分布 / 年龄段分布）

**工具**：问卷星（注册免费用户即可发起、收集、导出原始数据）

## 3.4 "企业可实施性"内评

**目标**：由小组成员为企业自身打分，量化"我们能不能做好、说出来、持续做"。

**工作内容**：

1. 每个卖点对应一个题组，3 个维度
   - **可行性**（1–10）：现有能力/资源能否落地（研发、供应链、合规）
   - **可传播性**（1–10）：是否容易用一句话说清楚并被记住
   - **可持续性**（1–10）：3 年内是否可被竞品快速跟进（壁垒强度）
2. 评分主体：小组全员独立打分，取均值；差异 ≥2 分的项需讨论收敛
3. 与 W1 价值体系交叉验证
   - W1 中得分 ≥6 分的测评点 → 对应卖点可行性高
   - W1 中得分 ≤3 分的测评点 → 对应卖点可行性低，需外部资源/合作

**评分规则**：企业可实施性 = 可行性 × 可传播性 × 可持续性的几何均值（或加权和，各 1/3 权重）

**产出物**：
- 企业可实施性得分表（卖点 / 三维分 / 均分 / 关键风险点）
- 与 W1 测评点的对应关系矩阵（哪些卖点由哪些测评点支撑）

## 3.5 双维矩阵 + 价值主张提炼

**目标**：把 3.3 和 3.4 的得分投到二维矩阵上，确定核心、场景差异化、次级三档卖点。

**工作内容**：

1. 绘制矩阵
   - X 轴：客户合意性（1–10）
   - Y 轴：企业可实施性（1–10）
   - 阈值建议：均分 ≥7 为"高"，否则为"低"
   - 四个象限：双高 / 客户高企业低 / 客户低企业高 / 双低
2. 卖点分档
   - **核心卖点**：双高象限，跨场景通用（如：三场景模式切换、跨场景认证背书）
   - **场景差异化卖点**：双高 + 场景特定，每个主战场场景选 1 个
   - **次级支撑**：双高但场景弱通用、或单高象限但仍需保留作为背书
   - **剔除**：双低或单低且无战略意义的卖点
3. 写出价值主张候选句
   - 公式：[场景人群] + [核心卖点] + [差异化卖点] + [可量化利益]
   - 例：模板——"为 [谁] 而生的 [品类]——[怎么做]，[带来什么可量化结果]"

**产出物**：
- "客户合意性-企业可实施性"矩阵散点图（标卖点编号）
- 卖点分档表（核心 / 场景差异化 / 次级支撑 / 剔除 四档）
- 价值主张候选句（3–5 条，供 3.6 收敛）

## 3.6 品牌定位陈述

**目标**：把 3.5 的结论压缩成一句话定位陈述 + 一段扩展说明。

**四要素结构**：
1. **品类**：卖的是什么（产品/服务类别）
2. **目标客群**：为谁而做（场景 + 人群）
3. **差异化卖点**：跟别人不一样在哪（核心 + 场景差异化）
4. **可量化利益**：用户得到什么（最好有数字）

**模板**：
> 为 **[目标客群]** 而生的 **[品类]**——**[差异化卖点 1 + 2 + 3]**，**[可量化利益]**。

**验收标准**：
- ≤30 字（中文）或 ≤15 词（英文 tagline）
- 不含"我们""最好的""领先的"等自夸词
- 三场景并行时，三卖点分别对应三场景
- 利益点必须可被验证（认证、参数、用户证言均可）

**产出物**：
- 定位陈述终稿（中文主陈述 + 英文 tagline）
- 与参考品牌定位陈述的对比（行业标杆、跨界标杆各 1 条）

## 3.7 品牌个性与视觉体系

**目标**：把抽象的定位陈述具象化为可感知的品牌人格与视觉语言。

**工作内容**：

1. **品牌人格（3–4 个 MBTI 维度）**
   - 能量来源：E 外向 / I 内向
   - 信息获取：S 实感 / N 直觉
   - 决策方式：T 思考 / F 情感
   - 生活方式：J 判断 / P 感知
   - 例：INFJ = 内敛但有信念、用直觉把握用户情绪、决策兼顾情感与逻辑、有计划地持续推进
2. **视觉识别系统（VI）**
   - Logo 风格：3 种候选方向 + 色彩心理学说明
   - 主色 + 辅色：色号（Hex/RGB）+ 应用场景
   - 字体：中文（思源黑体/方正悠黑等）+ 英文（Inter/Roboto 等）
   - 图形元素：辅助图形、icon 风格、摄影风格
   - 包装与详情页规范：版式、间距、栅格
3. **触点一致性检查**
   - 列出所有用户接触点（Amazon 详情页、独立站、APP、外包装、说明书、客服话术、社媒头像）
   - 每个触点对照 VI 规范做一致性 checklist

**产出物**：
- 品牌人格 MBTI 画像（一句话定义 + 4 维度详细解读）
- VI 规范手册（Logo 3 方案 + 配色 + 字体 + 辅助图形 + 应用示例）
- 触点一致性 checklist（≥10 个触点）

**工具**：DeepSeek（生成候选 + 色彩心理学说明）+ Figma/即时设计/Photoshop（视觉规范）

## 3.8 工作汇报 PPT

**目标**：把 3.1–3.7 的全部产出浓缩成 12–18 页可对外讲解的结构化汇报。

**建议结构**（每页 ≤5 个要点）：

| 页序 | 内容 | 依据 |
|---|---|---|
| 1 | 封面（品牌名 + 定位陈述 + 汇报人/日期） | 3.6 |
| 2 | 目标市场细分（场景细分表 + 需求强度对比） | 3.1 |
| 3 | 备选卖点池（5–9 个卖点一览） | 3.2 |
| 4 | 客户合意性得分（Top 卖点 + 关键证据） | 3.3 |
| 5 | 企业可实施性得分（Top 卖点 + 关键风险） | 3.4 |
| 6 | 双维矩阵散点图 + 卖点分档 | 3.5 |
| 7 | 核心价值主张（3–5 条候选） | 3.5 |
| 8 | 品牌定位陈述（终稿 + 中英对照） | 3.6 |
| 9 | 品牌人格 MBTI 画像 | 3.7 |
| 10 | VI 视觉规范（Logo + 配色 + 字体） | 3.7 |
| 11 | VI 应用示例（详情页 / 包装 / 社媒） | 3.7 |
| 12 | 与标杆品牌定位对比 | 3.6 |
| 13 | 下一步行动计划（衔接 W4 营销组合） | — |
| 14–18 | 备用页（调研数据、问卷截图、设计稿备选） | — |

**验收标准**：
- 12 页核心 + 3–6 页备用，总计 ≤18 页
- 每页 1 个核心信息（图 > 表 > 字）
- 价值主张矩阵必须可视化（散点图或热力图）
- 定位陈述页用大字号单独成页

**工具**：Kimi PPT（输入大纲自动生成，可二次排版）

## 验收 Checklist（工作坊-3 完结前自查）

- [ ] 3 个主战场场景已选定，并标注需求强度
- [ ] 备选卖点池 ≥5 项且 ≤9 项，覆盖三场景共同 + 各场景差异化
- [ ] 客户合意性问卷每场景 ≥30 份有效样本，合计 ≥150 份
- [ ] 企业可实施性小组内已收敛（差异 <2 分）
- [ ] 双维矩阵已绘制并完成卖点四档分档
- [ ] 定位陈述 ≤30 字，符合四要素结构
- [ ] 品牌人格已用 MBTI 定义，VI 规范手册覆盖 ≥5 个触点
- [ ] PPT 已完成，页数与结构符合模板
- [ ] 与 W1 价值体系交叉验证：核心卖点由 ≥6 分的测评点支撑
- [ ] 与 W2 目标市场一致：定位陈述中明示该市场的客群与品类

## 衔接关系

```
W1（价值体系 15 测评点）
    ↓
W2（市场吸引力×竞争力矩阵 → 选定目标市场）
        ↓
W3（本方法：价值主张 + 定位 + VI）
        ↓
W4（基于 W3 定位陈述制定营销组合 4P）
```

W3 的核心定位陈述将被 W4 的 4P（产品/价格/渠道/促销）引用——**产品**对照定位中的"差异化卖点"、**价格**对照"可量化利益"、**渠道**对照"目标客群"、**促销**对照"品牌人格与 VI"。
