## 页面结构

### 顶部工具栏

- 「从 Work 1–4 自动汇总」主按钮：一键拉取全部上游数据填入各章节。
- 「全部折叠 / 全部展开」
- 「打印 / 导出 PDF」
- 「复制为 Markdown」：把整份策划书导出为 .md 文件下载。
- 「让 AI 润色全文」（双模式）：逐章调 LLM 润色，保留事实，只改表达。

### 封面

四个输入框：标题、副标题、小组、日期（日期默认今天，可改）。
AI 辅助：「让 AI 起标题」（基于 SBU + 目标市场 + 价值主张生成 5 个备选）。

### 摘要

300–500 字文本区。
- 「从各章自动生成摘要」按钮：拼接各章核心句，压缩到 500 字内。
- 「让 AI 润色摘要」（双模式）。

### 目录

自动列出后续章节（1–5 + 参考文献），不可编辑。点击章节标题跳转锚点。

## 1. 企业及业务概况

字段：大文本区。

**「从 Work 1 汇总」**按钮：
- SBU 名称、一句话说明、行业、公司
- 品牌价值体系（一级 + 二级指标）
- 改进建议（Work 1 ）

拼成结构化文本填入。用户可编辑；编辑后该章标记 `edited=true`，下次点汇总不覆盖（提示"已人工编辑，是否强制覆盖？"）。

**AI 辅助**：「让 AI 改写为本章正文」（双模式）—— 把要点变成流畅的策划书语言。

---

## 2. 营销环境分析

### 2.1 PEST

四个文本区：政治 / 经济 / 社会 / 技术。

- 「从 Work 1  带入」按钮：把 Work 1 PEST 结果按关键词拆到四个框（简单正则拆分，拆不准用户手动调）。
- 每个框可独立编辑。
- 「让 AI 补充」按钮：基于 SBU + 目标市场，让 LLM 补全某一维度（双模式）。

### 2.2 SWOT

四列可增删条目（优势/劣势/机会/威胁），每列一个 tag 列表：
- 输入回车添加
- 每条可删除、可拖拽排序
- AI 辅助：「从 Work 1–2 数据提取 SWOT」（双模式）
  - 优势/劣势 ← Work 2 竞争力评分、Work 1 品牌资产
  - 机会/威胁 ← Work 2 吸引力评分、Work 1 PEST
  - 输出 JSON 填入四列

### 2.3 SWOT 矩阵图

按 [README.md](README.md) 选型：**不使用 lieflat**，SWOT 是文字网格不是数据编码。直接 Atelier 直角 2×2 hairline 网格：

```
┌─────────────────┬─────────────────┐
│ 优势 S          │ 劣势 W          │
│ • ...           │ • ...           │
├─────────────────┼─────────────────┤
│ 机会 O          │ 威胁 T          │
│ • ...           │ • ...           │
└─────────────────┴─────────────────┘
```

- 四象限底色取 `ATELIER.QUAD.*`（栗色/暖灰/中性灰/警示淡底）。
- 四列条目同步显示。
- 交叉策略（SO/ST/WO/WT）可选附加区，每个策略一句话，由 AI 生成或手填。

## 3. 营销战略（STP）

### 细分（Segmentation）

文本区。可从 Work 1  客户画像 + Work 3 目标客群带入。

### 目标市场（Targeting）

- 从 Work 2 自动带入选定市场名 + 理由 + 吸引力/竞争力总分。
- 显示 Work 2 矩阵缩略图（只读，点击跳转 Work 2）。
- 可补充说明。

### 定位（Positioning）

- 从 Work 3 带入定位陈述、价值主张、slogan、品牌人格。
- 可编辑。

**「让 AI 撰写 STP 章节」**（双模式）：基于上述数据生成连贯的章节正文。

---

## 4. 营销组合（4P / 4C）

### 4P 自动汇总

四个文本区（产品/价格/渠道/促销），每个有「从 Work 4 带入」按钮：
- 产品 ← Work 4  的 `aiResult` + SKU + 核心差异化
- 价格 ← Work 4  的策略 + 价格梯度
- 渠道 ← Work 4  的渠道组合 + 结构树（树以文字描述带入，图片不嵌入）
- 促销 ← Work 4  的传播主题 + 媒体组合 + 公关活动

### 4C 补充

四个文本区（客户价值/客户成本/客户便利/客户沟通），由用户手填或 AI 从 4P 转换：

**「从 4P 转 4C」**按钮（双模式）：
- 客户价值 ← 产品
- 客户成本 ← 价格（含时间/心理成本，不止金钱）
- 客户便利 ← 渠道
- 客户沟通 ← 促销（双向沟通而非单向推送）

## 5. 总结与展望

文本区。AI 辅助：「让 AI 基于前 4 章生成总结与展望」（双模式），300–500 字，包含：
- 核心战略回顾
- 关键风险与应对
- 阶段性目标（6/12/24 个月）

## 打印 / 导出

- `window.print()` + `@media print`：
  - 隐藏所有操作按钮、tab、AI 面板
  - 所有折叠章节强制展开
  - 封面单独一页
  - 每章 `page-break-before: always`
  - SWOT 矩阵用 print 友好的黑白边框
- 「复制为 Markdown」：生成完整 .md 文件下载（含标题层级、表格、列表），方便用户贴到 WPS/Google Docs/Notion。
- 不直接生成 .docx（单文件边界，保持零依赖）。
