# 海外目标市场选择 SOP

> **一句话定位**：用"市场吸引力 × 业务竞争力"二维矩阵，把候选国家量化排序，落象限后做主战场/观察期/放弃三档决策。
> **适用场景**：任何 SBU 立项后、进入 STP 阶段前，需要在多个海外国家/地区之间做出"先去哪个"决策。
> **前置条件**：SBU 定义清晰（业务范围、目标客群、产品/服务已明确），否则吸引力与竞争力都无从评估。
> **耗时**：4-5 天（含打分讨论会）。

---

## 总览：6 步流程

| 步骤 | 产出 | 耗时 |
|------|------|------|
| Step 1｜确定筛选维度 | 候选国清单（5-10）→ 保留 3 个 | 0.5 天 |
| Step 2｜构建市场吸引力评估体系 | 4×2 指标表 + 权重 | 1 天 |
| Step 3｜构建业务竞争力评估体系 | 4×2 指标表 + 权重 | 1 天 |
| Step 4｜填数据 + 独立打分 | 24 格评分 + 数据来源 | 1 天 |
| Step 5｜矩阵落象限 + 决策 | 散点图 + 三档决策卡 | 0.5 天 |
| Step 6｜汇报 + 知识沉淀 | 10 页 PPT + 模板归档 | 0.5 天 |

---

## Step 1｜确定筛选维度（0.5 天）

**目标**：从所有可能的国家/地区中，先用粗筛维度砍到 3 个，进入精细评估。

### 1.1 候选国清单构造（5-10 个）

按业务相关性从三个层级撒网：

- **气候/基础设施层**：根据产品形态推断潜在市场（如温控器考虑美/欧/日/东南亚/中东/澳洲）
- **客户结构层**：B 端出海口（中东/东南亚/南美）+ C 端出海口（美/欧/日/澳）
- **既有关系层**：母公司已供货客户所在国、母公司海外子公司分布

### 1.2 初筛淘汰标准（最多 3 条）

每条标准必须可观测、可量化，避免主观偏好：

| 维度 | 示例标准 | 数据来源 |
|------|---------|---------|
| 文化极端距离 | Hofstede UAI > 80 且无本地合作方 | Hofstede Insights |
| 认证成本极高 | 主要认证预算 > 单市场首年营收 20% | 认证机构询价 |
| 市场规模过小 | 年市场规模 < 1 亿美元 且 CAGR < 5% | Statista / Euromonitor |
| 政治高风险 | 战争/制裁/重大贸易壁垒 | 商务部国别贸易投资环境报告 |

### 1.3 输出

- **候选国清单**（含淘汰原因）
- **保留进入 Step 2 的 3 个市场**

### 易错点

- ❌ 直接选 3 个市场就开打——没有淘汰过程，主观偏好会污染后续量化打分
- ❌ 初筛标准用主观感受（如"那个国家感觉不好"）——失去可解释性，决策不能复盘

---

## Step 2｜构建市场吸引力评估体系（1 天）

**目标**：评估"这个市场好不好"，输出 4 个一级指标 × 2 个二级指标 = 8 项评分表。

### 2.1 指标体系（8 项）

| 一级 | 二级 | 权重 | 评分要素 |
|------|------|------|---------|
| 1. 经济因素 25% | 1.1 市场规模与中高端客单价容量 | 12.5% | 行业总规模、CAGR、目标价格段容量 |
| | 1.2 经济景气度与消费意愿 | 12.5% | GDP 增速、可支配收入、通胀指数 |
| 2. 政治法律因素 25% | 2.1 母国出海政策与贸易摩擦 | 12.5% | 关税、贸易壁垒、汇率管制 |
| | 2.2 认证要求与合规成本 | 12.5% | 强制性认证清单、单产品认证费用 |
| 3. 社会文化因素 25% | 3.1 目标客群需求强度 | 12.5% | 客群规模、痛点急切度、付费意愿 |
| | 3.2 Hofstede 文化维度匹配度 | 12.5% | 个人主义/集体主义、不确定性规避 |
| 4. 风险因素 25% | 4.1 汇率波动与回款风险 | 12.5% | 货币波动率、外汇管制 |
| | 4.2 物流时效与库存风险 | 12.5% | 海运/空运时效、清关复杂度 |

### 2.2 权重确定方法

**推荐：德尔菲法两轮收敛（简化版）**

1. 找 3-5 位公司高管/外部顾问，每人独立给 8 项打分（建议满分 100）
2. 第一轮后开会，展示大家结果，讨论分歧 >15 分的项目
3. 第二轮独立打分，取均值
4. 标准化为 100% 总权重

### 2.3 输出

- **市场吸引力评估表**（4×2 × 3 市场 = 24 格，权重合计 100%）

### 易错点

- ❌ 8 项权重全用 12.5%——表面看"均衡"，实际是"不知道哪个更重要"的表现
- ❌ 照搬上一轮的权重——业务和环境变了，权重必须重做
- ❌ 把"毛利率"塞进吸引力——毛利率是企业能力，不是市场吸引力

---

## Step 3｜构建业务竞争力评估体系（1 天）

**目标**：评估"我能不能打这个市场"，输出与吸引力对称的 4×2 指标表。

### 3.1 指标体系（8 项）

| 一级 | 二级 | 权重 | 评分要素 |
|------|------|------|---------|
| 1. 市场信息能力 25% | 1.1 客户需求数据可获取性 | 12.5% | 调研报告、平台评论、垂直媒体覆盖 |
| | 1.2 竞品数据可监测性 | 12.5% | 销量榜单、流量数据、价格跟踪 |
| 2. 营销渠道能力 25% | 2.1 主流电商平台成熟度 | 12.5% | 平台市占率、卖家生态、物流基础设施 |
| | 2.2 当地 KOL 资源与合作渠道 | 12.5% | 垂直 KOL 数量、活跃度、合作模式 |
| 3. 认证与合规能力 25% | 3.1 既有认证可复用度 | 12.5% | 已认证清单 vs 目标市场要求清单 |
| | 3.2 当地法律服务与合规成本 | 12.5% | 律师/合规咨询可获取性、人天成本 |
| 4. 产品与品牌能力 25% | 4.1 既有客户基础可迁移性 | 12.5% | 母公司 B 端客户分布、渠道延伸 |
| | 4.2 C 端品牌能力起点 | 12.5% | 品牌认知、UGC 存量、Review 数量 |

### 3.2 与吸引力的对称性

吸引力与竞争力必须**维度对称但方向相反**——吸引力看"市场"，竞争力看"我"。两者结构相同便于横向对比，也便于矩阵落点。

### 3.3 输出

- **业务竞争力评估表**（4×2 × 3 市场 = 24 格）

### 易错点

- ❌ 把"我希望做这个市场"混入竞争力——竞争力是客观能力评估，不是主观意愿
- ❌ 4.2 C 端品牌能力一律打 0——应该根据是否真的从零起步打分，避免不同市场同质化

---

## Step 4｜填数据 + 独立打分（1 天）

**目标**：每个分数都附数据来源，避免主观。

### 4.1 数据来源规范

每个评分格必须包含：

```
[二级指标]：[分数]/10
依据：[1-2 条具体数据来源 + 数字]
```

**示例**：
```
1.1 市场规模与中高端客单价容量（美国）：8/10
依据：Parks Associates 2025 年数据，美国智能温控器市场 16.7 亿美元；
      Precedence Research 预测 2030 年突破 11 亿美元/年销量。
```

### 4.2 评分原则

- **0-10 整数制**（不用 7.5 这样的半值，便于加权）
- **3 人独立打分**（业务负责人 + 产品经理 + 外部顾问），差异 >2 分必须开会讨论
- **加权总分简化为 0-100**（不是 0-10，方便跨市场对比）

### 4.3 输出

- 16 个评分格（每个市场 8 项）+ 数据来源
- 三大市场加权总分（吸引力 100 / 竞争力 100 各一档）

### 易错点

- ❌ "我觉得应该是 7 分"——没有数据来源就是主观
- ❌ 一个人打完所有分数——失去交叉验证
- ❌ 把"目标值"和"评估值"混为一谈——评估的是客观现状，不是目标

---

## Step 5｜矩阵落象限 + 决策（0.5 天）

**目标**：把两个 0-100 分落到二维矩阵，决定先打哪个市场。

### 5.1 矩阵四象限

| 象限 | 吸引力 | 竞争力 | 含义 | 动作 |
|------|--------|--------|------|------|
| 第一象限 | 高 | 高 | 优质市场 | 大力投入，80%+ 资源 |
| 第二象限 | 低 | 高 | 维持现状 | 守住现有份额，不扩张 |
| 第三象限 | 低 | 低 | 双低 | 放弃或观察 |
| 第四象限 | **高** | **低** | **潜力市场** | **补能力后进入** |

### 5.2 决策原则

- **必须有且仅有一个主战场**：80% 资源集中投入
- **观察期市场最多 5% 资源**：维持数据收集 + 小规模测试
- **不能因为"差不多"就平均资源**：平均即全输
- **象限边界模糊时，优先选第一象限**（高确定性）

### 5.3 输出

- **散点图**（横轴=竞争力，纵轴=吸引力，标注 3 个市场）
- **三档决策卡**：
  - 主战场（哪个 + 资源占比）
  - 观察期（哪些 + 观察指标）
  - 放弃/暂缓（哪个 + 触发再评估的条件）

### 5.4 决策卡模板

```
【主战场】市场 X
  - 吸引力：__/100  竞争力：__/100
  - 象限：第 X 象限
  - 资源占比：80%
  - 关键动作：[3-5 条具体动作]
  - 6 个月里程碑：[量化指标]

【观察期】市场 Y
  - 吸引力：__/100  竞争力：__/100
  - 资源占比：5%
  - 观察指标：[2-3 条可监控数据]
  - 重新评估时点：[具体日期]

【暂缓】市场 Z
  - 触发再评估的条件：[如 GDP 增速转正 / 认证成本下降 30%]
```

### 易错点

- ❌ 散点图不画，光列分数——失去视觉决策依据
- ❌ 三个市场都"重要"——主战场没有，必然资源稀释
- ❌ 决策卡不写"触发再评估条件"——暂缓变成永久放弃

---

## Step 6｜汇报 + 知识沉淀（0.5 天）

**目标**：把全套流程浓缩为可汇报材料 + 可复用模板。

### 6.1 PPT 10 页

| 页码 | 内容 |
|------|------|
| 1 | 候选国清单 + 初筛维度 + 淘汰原因 |
| 2 | 三大市场吸引力评估表（含数据来源） |
| 3 | 三大市场业务竞争力评估表（含数据来源） |
| 4 | 市场吸引力-业务竞争力矩阵图 |
| 5 | 决策结论 + 资源分配方案 |
| 6 | 风险与应对预案 |
| 7 | 关键假设与敏感度分析 |
| 8 | 后续行动项（向 STP 下一阶段交接） |
| 9 | 6 个月里程碑与复盘节点 |
| 10 | 附录：评分数据来源汇总 |

### 6.2 知识沉淀

将以下模板归档至 wiki，下次复用：

- **候选国初筛维度清单**
- **市场吸引力评估表模板**（4×2）
- **业务竞争力评估表模板**（4×2）
- **矩阵决策卡模板**

### 易错点

- ❌ PPT 只列分数，不列来源——汇报时被质疑无法当场回应
- ❌ 没有敏感度分析——单一假设错了结论就崩，没有备份方案

---

## 检查清单（SOP 使用自检）

完成全部 6 步后，逐项检查：

- [ ] 全程评分都有数据来源（非主观）
- [ ] 3 人独立打分，差异 >2 分的项目已开会讨论
- [ ] 决策卡明确唯一主战场（不能 3 个平分秋色）
- [ ] 暂缓市场写了"触发再评估条件"
- [ ] 评分表 + 矩阵图 + 决策卡三件套完整
- [ ] PPT 包含敏感度分析（关键假设错了怎么办）
- [ ] 模板已归档至 wiki，下次复用无需重新设计
