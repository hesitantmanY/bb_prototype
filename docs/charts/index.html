docs/charts/ · Lieflat Charts 画廊

本目录是 Brand-building 项目的 lieflat-charts 风格图的标准位置。下面是当前沉淀的 8 张图，全部使用 Mono 灰阶与统一工作流。 点击任一卡片进入独立 HTML（双击也能开）。数据是通用教学样张，可按需替换。

workshop1 客户研究

09
SWOT 矩阵
L4 ARC MATRIX 思路
2×2 象限（内部/外部 × 积极/消极）；S/O 强调（深），W/T 弱化（浅）；附 SO/WO/ST/WT 战略提示。
workshop5 战略分析
使用约定 · 所有图都使用 Mono 灰阶（INK/PAPER/MUTED/FAINT/GRID + 7 阶 ladder）， 卡片结构统一为「结论式 h2 + 副标题（带图例）+ SVG + 大写 src」， 动画统一为 obsReveal（滚入播 / 点击重播 / reduced-motion 降级）。
替换数据 · 每张图顶部的 DATA / POINTS / SEGS 常量是唯一需要改的地方。 改完直接双击 HTML 即可看新版。
