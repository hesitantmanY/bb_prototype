备选区域 / 国家 / 市场

由小组共同商定。默认名称只是占位符。
指标解决“看什么”；权重解决“谁更重要”。

预置课件示例：市场吸引力=需求采购50%、规模成长30%、行业趋势20%；业务竞争力=竞争优势60%、能力资源20%、产业链关系20%。可全部修改。

0–10分量化评估

总分 = Σ（指标评分 × 指标权重）
建议：每个分数最好写出数据、行业报告、访谈或企业经验依据，避免变成“凭感觉打分”。

四象限决策

课件给出四象限逻辑，但没有规定0–10体系的固定切分值。这里默认5分，可自行调整。

优质市场
高吸引力 × 高竞争力 → 进入 / 大力投入
新兴市场
高吸引力 × 低竞争力 → 进一步分析 / 考虑进入
成熟市场
低吸引力 × 高竞争力 → 保持
不良市场
低吸引力 × 低竞争力 → 放弃
